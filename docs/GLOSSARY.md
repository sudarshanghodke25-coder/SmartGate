# Glossary

- **PWA:** Progressive Web App; a web app that can be installed and offers app-like behavior.
- **Gate pass:** A record of a student's approved request to leave campus.
- **QR token:** A code carried in a QR image and checked online by the server.
- **RLS:** Row Level Security; database rules that restrict which rows a user can access.
- **Edge Function:** Server-side code that handles requests outside the trusted browser.
- **Idempotent operation:** Repeating the same request does not create duplicate effects.
- **Atomic operation:** A group of changes succeeds together or fails together.
- **Audit log:** A traceable record of important system actions.
- **Fail closed:** If the system cannot verify authorization, it does not authorize the action.
- **MVP:** Minimum Viable Product; the smallest useful version to build and test.
